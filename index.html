QoL Add-on Builder

Pick the features you want, then download a pack with only those. Everything is built in your browser; nothing is uploaded.

Bump it every upload so devices don't keep a cached copy.

Install

  1. Open the downloaded .mcaddon; Minecraft imports it.
  2. Create or edit a world, then Behavior Packs, and activate QoL Add-on.
  3. For a Realm, upload that world (Realms settings, Replace world). Switch players download the pack when they join.
  4. In game, use a clock for the menu. Each feature can be switched off per player in its Settings page.
